# Agentic Development Prompt

Implement the rate limiting feature defined in `spec.md`.

Work autonomously through the complete engineering task:

1. Inspect the baseline and repository guidance.
2. Plan the smallest compatible change.
3. Implement the feature.
4. Add or update tests.
5. Run the relevant test suite.
6. Diagnose and repair failures without asking for help when the failure can be resolved from repository evidence.
7. Re-run validation until all visible acceptance criteria pass.
8. Review the diff for unnecessary changes and dependency violations.
9. Return a concise summary of the implementation, tests run, repairs made, and any unresolved risk.

Follow `context/ARCHITECTURE.md`, `context/ENGINEERING_RULES.md`, and `context/AGENTS.md`. Do not inspect hidden evaluator tests.
