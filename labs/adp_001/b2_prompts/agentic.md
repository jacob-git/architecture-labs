# Agentic Development Prompt

Implement the caching feature defined in `spec.md`.

Work autonomously through the complete engineering task:

1. Inspect the baseline and repository guidance.
2. Plan the smallest compatible change.
3. Implement the feature.
4. Add or update tests.
5. Run the relevant visible test suite.
6. Diagnose and repair visible failures without asking for help when repository evidence is sufficient.
7. Re-run validation until visible acceptance criteria pass.
8. Review the implementation for unnecessary complexity and dependency violations.
9. Return a concise summary of the implementation, tests, repairs, and unresolved risk.

Follow `b2_context/ARCHITECTURE.md`, `b2_context/ENGINEERING_RULES.md`, and `b2_context/AGENTS.md`. Never inspect hidden evaluator tests.
