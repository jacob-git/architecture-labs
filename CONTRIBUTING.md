# Contributing

Contributions that improve reproducibility, expose failure modes, or strengthen experimental controls are welcome.

## Ground rules

- Use fictional, synthetic, public, or openly licensed material only.
- Do not contribute employer systems, internal projects, customer data, credentials, private operational details, or confidential context.
- Never commit API keys or generated result files that have not been reviewed.
- Do not change a fixed corpus after a run merely to improve a metric. Explain the defect, version the change, and preserve the earlier result.
- Separate model behavior, governance behavior, integration failures, and harness errors.
- Report negative and ambiguous findings alongside successful outcomes.

For a new lab, include a research question, falsifiable hypothesis, methodology, fixed inputs, reproduction command, results policy, limitations, and license-compatible sources.
